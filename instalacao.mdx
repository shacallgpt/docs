# 📦 Como Instalar

## Guia Completo de Instalação

Siga todos os passos na ordem correta para preparar seu sistema para o HYPEX AIM.

<Warning>
⚠️ **ATENÇÃO:** É essencial seguir todos os passos na ordem apresentada para evitar problemas durante a instalação.
</Warning>

---

<Steps>
<Step title="📹 1. INSTALAR APOWERREC">

Instale o software de gravação de tela APowerRec para garantir o funcionamento correto do cheat.

<Card title="Download APowerRec" icon="video" href="https://www.apowersoft.us/screen-recording-br">
Acesse o site oficial para baixar o APowerRec
</Card>

**📹 Passo a passo da instalação:**

1. ✨ Baixe o instalador do APowerRec no site oficial
2. 🔧 Execute o instalador como administrador
3. ✅ Siga as instruções do assistente de instalação
4. 🚀 Abra o APowerRec após a instalação

<Info>
💡 **Dica:** Mantenha o APowerRec instalado e atualizado para garantir o melhor desempenho.
</Info>

</Step>

<Step title="⚙️ 2. INSTALAR RUNTIMES">

Instale todos os runtimes necessários para o funcionamento do cheat. Esses componentes são essenciais para a execução correta do HYPEX AIM.

<Card title="Download All-in-One Runtimes" icon="gear" href="https://www.allinoneruntimes.org/">
Instale todos os runtimes necessários de uma vez
</Card>

**📋 Passo a passo da instalação:**

1. 📥 Baixe o All-in-One Runtimes
2. 🔧 Execute o instalador como administrador
3. ✅ Selecione todos os componentes recomendados
4. ⏳ Aguarde a instalação completa
5. 🔄 Reinicie o computador se solicitado

<Warning>
⚠️ Certifique-se de instalar todos os runtimes necessários para evitar erros durante a execução do cheat. Não pule nenhum componente!
</Warning>

</Step>

<Step title="🖥️ 3. CONFIGURAR RESOLUÇÃO DO MONITOR">

Configure a resolução do seu monitor para 100% (escala padrão) para evitar problemas de interface e garantir que o cheat funcione corretamente.

**📋 Como configurar:**

1. 🖱️ Clique com o botão direito na área de trabalho
2. ⚙️ Selecione "Configurações de exibição" ou "Display settings"
3. 📏 Localize a opção "Escala" ou "Scale"
4. ✅ Defina para 100% (Recomendado)
5. 🔄 Aplique as alterações

<Info>
💡 A resolução do monitor deve estar configurada para 100% (escala padrão) para garantir que o cheat funcione corretamente. Valores diferentes podem causar problemas de interface.
</Info>

</Step>

<Step title="🎮 4. DESLIGAR SOBREPOSIÇÃO NVIDIA (SE INSTALADO)">

Se você tem o NVIDIA GeForce Experience instalado, desligue a sobreposição (Overlay) para evitar conflitos com o cheat.

**📋 Como fazer:**

1. 🔧 Abra o NVIDIA GeForce Experience
2. ⚙️ Vá em Configurações (ícone de engrenagem no canto superior direito)
3. 📋 Procure por "Sobreposição in-game" ou "In-game overlay"
4. ❌ Desmarque a opção "Sobreposição in-game"
5. 💾 Salve as alterações
6. 🔄 Reinicie o computador se necessário

<Warning>
⚠️ Esta etapa é importante se você possui NVIDIA GeForce Experience instalado. Ignorar este passo pode causar conflitos e problemas durante o uso do cheat.
</Warning>

</Step>
</Steps>

---

## ✅ Verificação Final

Antes de prosseguir, certifique-se de que:

<Check>
- ✅ APowerRec está instalado e funcionando
- ✅ Todos os runtimes foram instalados corretamente
- ✅ Resolução do monitor está em 100%
- ✅ Sobreposição NVIDIA está desativada (se aplicável)
</Check>
