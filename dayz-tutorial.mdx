## 6. Configurar a Overlay

<Warning>
  A ordem de abertura é **extremamente importante**. Qualquer variação pode impedir o menu de aparecer.
</Warning>

### Ordem Correta

<Steps>
  <Step title="1 — Crosshair X">
    Abra primeiro o Crosshair X. Espere carregar completamente e confirme que a mira está aparecendo.
  </Step>
  <Step title="2 — DayZ">
    Abra o DayZ e entre no servidor normalmente.

    <Warning>
      O jogo deve estar em **MODO JANELA**. Em tela cheia exclusiva, o menu não aparecerá.
    </Warning>
  </Step>
  <Step title="3 — Entrar em um servidor">
    Conecte-se ao servidor antes de abrir o software.
  </Step>
  <Step title="4 — Abrir o Software">
    Com Crosshair X ✅, DayZ ✅ e servidor ✅ — abra o software, faça login e pressione `H` para abrir o menu.
  </Step>
</Steps>

## Solução de Problemas

### ❌ Menu não aparece

<AccordionGroup>
  <Accordion title="Verifique estes pontos">
    - Crosshair X foi aberto **antes** do software
    - Crosshair X está funcionando e a mira aparece sobre o DayZ
    - DayZ está em **modo janela**
    - Você entrou no servidor **antes** de abrir o software
    - Escala do Windows está em **100%**
    - Software foi aberto por **último**
  </Accordion>

  <Accordion title="Se ainda não aparecer">
    Feche tudo na seguinte ordem:

    1. Software
    2. DayZ
    3. Crosshair X

    Depois abra novamente:

    **Crosshair X → DayZ → Entrar no servidor → Software → `H`**
  </Accordion>
</AccordionGroup>

### ⚠️ Abri as opções mas não funciona

Pode haver duas instâncias do programa abertas.

<Steps>
  <Step title="Abra o Gerenciador de Tarefas">
    Pressione `CTRL + SHIFT + ESC`.
  </Step>
  <Step title="Verifique os processos">
    Procure o software. Se aparecer mais de uma vez, feche todas as instâncias.
  </Step>
  <Step title="Reabra corretamente">
    Deixe somente o DayZ aberto, abra novamente o software e pressione `H`.
  </Step>
</Steps>

### ⬛ Tela preta

1. Desative a configuração que acabou de ativar.
2. Feche o software e o DayZ.
3. Abra novamente seguindo a ordem correta.

### 🐌 ESP travando

1. Feche programas desnecessários.
2. Verifique se a CPU/RAM não está em 100%.
3. Abra na ordem: **Crosshair X → DayZ → Servidor → Software**.

### 📁 Menu desconfigurado

Verifique: resolução **1920×1080**, escala **100%**, DayZ em **modo janela** — depois reinicie tudo.
