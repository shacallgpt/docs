<Steps>
<Step title="📹 1. INSTALAR APOWERREC">

Instale o software de gravação de tela APowerRec para garantir o funcionamento correto do cheat.

<Card title="Download APowerRec" icon="video" href="https://www.apowersoft.us/screen-recording-br">

**📹 Minitutorial APowerRec:**

1. ✨ Abrir o APowerRec
2. 👁️ Verificar se a exibição está no seu monitor
3. 🔴 Clicar em "REC" e depois em "Trial"
4. ⏸️ Pausar a gravação
5. 🔽 Se quiser, clique com o botão direito e minimize a barra de atalho do APower

<Info>
💡 **Dica:** Depois de configurar o APowerRec, abra o cheat com o jogo aberto.
</Info>

<Step title="⚙️ 2. INSTALAR RUNTIMES">

Instale todos os runtimes necessários para o funcionamento do cheat. Esses componentes são essenciais para a execução correta do HYPEX AIM.

<Card title="Download All-in-One Runtimes" icon="gear" href="https://www.allinoneruntimes.org/">

<Warning>
⚠️ Certifique-se de instalar todos os runtimes necessários para evitar erros durante a execução do cheat.
</Warning>

</Step>

<Step title="🖥️ 3. RESOLUÇÃO DO MONITOR 100%">

Configure a resolução do seu monitor para 100% (escala padrão) para evitar problemas de interface e garantir que o cheat funcione corretamente.

<Info>
💡 A resolução do monitor deve estar configurada para 100% (escala padrão) para garantir que o cheat funcione corretamente.
</Info>

</Step>

<Step title="🎮 3.5. DESLIGAR SOBREPOSIÇÃO NVIDIA (SE INSTALADO)">

Se você tem o NVIDIA GeForce Experience instalado, desligue a sobreposição (Overlay) para evitar conflitos com o cheat.

**📋 Como fazer:**

1. 🔧 Abra o NVIDIA GeForce Experience
2. ⚙️ Vá em Configurações (ícone de engrenagem)
3. ❌ Desmarque "Sobreposição in-game"
4. 🔄 Reinicie o computador se necessário

<Warning>
⚠️ Esta etapa é importante se você possui NVIDIA GeForce Experience instalado. Ignorar este passo pode causar conflitos.
</Warning>

</Step>

<Step title="🚀 4. ABRA O JOGO E NO LOBBY ABRA O CHEAT">

Inicie o Valorant, entre no lobby e então execute o cheat.

<Info>
✅ **Ordem correta:** 1) Abra o Valorant → 2) Entre no lobby → 3) Execute o cheat
